# プレビュー生成モジュール仕様書

このドキュメントは、Web Archiveプロジェクトのプレビュー生成モジュールの詳細な仕様を定義するものです。このモジュールは、指定されたURLのスクリーンショットを生成する役割を担います。

## 1. モジュール概要

- **役割**: 指定されたURL（通常はアーカイブされたページの `/view/...` URL）のスクリーンショットを生成し、JPEGファイルとして保存する。
- **対応実装ファイル**: `src/modules/preview_generator.py`
- **使用ライブラリ**: Playwright

## 2. 機能要件

- **スクリーンショット生成**: 指定されたURLにヘッドレスブラウザでアクセスし、ページのレンダリング結果をキャプチャする。
- **ファイル保存**: 生成したスクリーンショットを指定されたファイル名で `previews` ディレクトリにJPEG形式で保存する。
- **ブラウザフォールバック**: Chromiumの起動に失敗した場合、Firefoxを使用して再試行する。
- **エラーハンドリング**: ブラウザの起動失敗、ページの読み込み失敗、スクリーンショット取得失敗などのエラーを適切に処理し、例外を発生させる。

## 3. インターフェース設計

### 3.1 主要関数
- **非同期関数**: `generate_preview(url: str, output_filename: str) -> str`
  - **説明**: 指定されたURLのスクリーンショットを生成し、指定されたファイル名で保存する。成功した場合、出力ファイル名を返す。
  - **引数**:
    - `url`: 文字列（スクリーンショット対象のURL）
    - `output_filename`: 文字列（保存するJPEGファイル名）
  - **戻り値**:
    - 成功時: 文字列（`output_filename`）
    - 失敗時: 例外をスロー
  - **処理フロー**:
    1. `previews` ディレクトリが存在しない場合は作成する。
    2. Playwrightを初期化する (`async_playwright()` コンテキストマネージャを使用)。
    3. Chromiumブラウザの起動を試みる。
    4. 失敗した場合、Firefoxブラウザの起動を試みる。
    5. どちらも失敗した場合、例外を発生させる。
    6. 新しいページを開く。
    7. ビューポートサイズを設定する（例: 1024x768）。
    8. 指定されたURLに移動する（タイムアウト時間を長めに設定）。
    9. ネットワークがアイドル状態になるまで待機する (`networkidle`)。
    10. スクリーンショットを指定されたパス (`previews/` + `output_filename`) にJPEG形式で保存する。
    11. ブラウザを閉じる。
    12. 出力ファイル名を返す。

### 3.2 依存モジュールとの連携
- このモジュールは `web_interface.py` のプレビューワーカ (`preview_worker`) から呼び出される。
- 成功/失敗の結果は呼び出し元のワーカに返され、ワーカがデータベース更新やSSE通知を行う。

## 4. 非機能要件
- **パフォーマンス**: Playwrightの起動とページ読み込みには時間がかかるため、非同期処理（ワーカとキュー）で実行し、メインのリクエスト処理をブロックしない。
- **安定性**: ブラウザの起動失敗やページ読み込みエラーに対するフォールバックとエラーハンドリングを行う。
- **リソース管理**: Playwrightのブラウザプロセスが適切に閉じられるようにする。

## 5. 使用ライブラリ
- **playwright**: ヘッドレスブラウザ操作、スクリーンショット取得。
- **asyncio**: 非同期処理の実行。

## 6. テスト方針
- **単体テスト**:
  - PlaywrightのAPI呼び出し（`launch`, `new_page`, `goto`, `screenshot`, `close` など）をモックし、関数が正しく呼び出されるか検証。
  - ブラウザ起動失敗時のフォールバック処理を検証。
  - スクリーンショット失敗時の例外発生を検証。
  - ファイルパスが正しく生成されるか検証。

## 7. 開発方針
- Playwrightの非同期APIを正しく使用する。
- エラーハンドリングを丁寧に行い、失敗した場合の原因を特定しやすくする。

この仕様書は、プレビュー生成モジュールの設計と実装の基盤となるものです。開発の過程で必要に応じて更新されます。
