# コンテンツ公開モジュール仕様書

このドキュメントは、Web Archiveプロジェクトのコンテンツ公開モジュールの詳細な仕様を定義するものです。このモジュールは、保存したコンテンツをランダムURLで公開し、閲覧可能にする役割を担います。

## 1. モジュール概要

- **役割**: データベースから取得したコンテンツをHTMLとしてレンダリングし、関連リソース（CSS, JavaScript, 画像）を適切にリンクして公開する。
- **対応実装ファイル**: `src/modules/content_publish.py`

## 2. 機能要件

- **コンテンツレンダリング**: 保存したHTMLコンテンツをレンダリングし、ブラウザで表示可能にする。
- **リソースリンク**: CSS, JavaScript, 画像などの関連リソースを適切にリンクし、元のページに近い形で表示。
- **リソース提供**: 画像やCSS, JavaScriptファイルを個別に提供するエンドポイントを用意。

## 3. インターフェース設計

### 3.1 主要関数
- **関数**: `render_content(content: dict) -> str`
  - **説明**: コンテンツデータをHTMLとしてレンダリングし、関連リソースをリンクした文字列を返す。
  - **引数**:
    - `content`: 辞書形式のコンテンツデータ
      ```
      {
        "html_content": "HTML本文",
        "resources": {
          "css": [{"url": "CSSのURL", "content": "CSS内容"}, ...],
          "js": [{"url": "JSのURL", "content": "JS内容"}, ...],
          "images": [{"url": "画像のURL", "webp_data": "WebP形式のバイナリデータ"}, ...]
        }
      }
      ```
  - **戻り値**:
    - 成功時: 文字列（レンダリングされたHTML）
    - 失敗時: 例外をスロー（呼び出し元でエラーハンドリング）
  - **処理フロー**:
    1. HTMLコンテンツをベースとして取得。
    2. 関連リソース（CSS, JS, 画像）のリンクを内部URLに書き換え。
    3. 書き換えたHTMLを返す。

### 3.2 内部関数（参考）
- **関数**: `rewrite_resource_urls(html_content: str, resources: dict) -> str`
  - HTML内のリソースURLを内部URLに書き換える。
- **関数**: `serve_resource(resource_type: str, index: int) -> bytes`
  - 指定されたリソース（CSS, JS, 画像）を返す。

### 3.3 依存モジュールとの連携
- このモジュールは他のモジュールに依存せず、独立して動作。
- Webインターフェースモジュールからコンテンツデータを受け取り、レンダリング結果を返す。
- 関連リソースの提供は、Webインターフェースモジュールのエンドポイントを通じて行う。

## 4. 非機能要件
- **パフォーマンス**: レンダリング処理を軽量に保ち、迅速なレスポンスを実現。
- **互換性**: 元のWebページの表示にできる限り近づけるよう、リソースリンクを正確に処理。
- **エラーハンドリング**: コンテンツデータが不完全な場合やリソースが見つからない場合に適切な例外をスロー。

## 5. 使用ライブラリ
- **BeautifulSoup**: HTMLの解析とURL書き換え。

## 6. テスト方針
- **単体テスト**:
  - `render_content` 関数の戻り値が正しいHTML構造を持つか。
  - リソースURLが正しく内部URLに書き換えられるか。
  - 不完全なデータに対するエラーハンドリング。
- **結合テスト**:
  - Webインターフェースモジュールとの連携で、コンテンツが正しく表示されるか。
